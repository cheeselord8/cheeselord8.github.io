# Alex Narizhnyi - CV Website

A static one-page CV site based on the supplied MyResume template. The profile and project details are fictional practice content for coursework. The public site is served from `https://cheeselord8.github.io/`.

## Run locally

Open `index.html` in a browser, or use Visual Studio Code with Live Server.

## Source files

The page is built with HTML, CSS, JavaScript, and the template's local Bootstrap and UI libraries. The image, styles, scripts, charts, and favicon are stored under `assets/`.

## LW8 additions

- The resume includes fictional education and project experience for coursework practice.
- The portfolio shows four SVG graphs recreated from the supplied MATLAB Lab Work 3 and 4 formulas/data.
- The Services section includes the required 4-by-3 HTML table, technology list, ordered workflow, and nested list.
- The Media Lab embeds the local Pexels MP4 and Pixabay MP3 files, plus the assigned YouTube video.
